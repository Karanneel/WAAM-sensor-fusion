# Revision after the repository review

The review found that nozzle Z could not affect deposited height in the original
process equations. The equal final wall errors were therefore an implementation
consequence. They did not establish that the controller absorbed estimator errors.

The local working copy subsequently switched to travel-speed control. This
revision completes that change by aligning measurement timing, separating build
seeds across all comparisons, and evaluating models without sensor inputs.

Changes made on 2026-11-01:

- Travel speed controls height; a custom final target also controls the intermediate trajectory.
- CTWD and EKF standoff refer to the same end-of-deposition state.
- EKF thermal derivatives include the height-dependent cooling term.
- Small physical differences are sampled per build, with explicitly assumed ranges.
- Training is identical across nominal, dropout and generator-variant comparisons.
- Learned sensor subsets include the empty set. Each estimator is reported separately.
- Covariance plots are labelled as filter uncertainty rather than Gramian/CRB results.
- The reference filter is no longer called an oracle or an achievable floor.
- Dropout scoring uses actual missing-scan masks and paired build-level comparisons.
- Public reports use descriptive experiment names and derive statements from calculated results.

## Earlier claims withdrawn

The original PASS statement is not retained as a valid gate evaluation. The
original code did not calculate the required masked metrics and paired intervals.
The replacement protocol and its outcomes are reported separately.

The original prediction scorecard changed metrics: P1/P2/P4 asked about final
wall error but were judged using state errors. On the original equal-error
outputs, P1's strict KF win and P2's crossover were not observed; P4's naive
baseline was within 10% in every condition. The equality was built into the
original experiment, so P3 did not demonstrate a meaningful control ranking
reversal. P5's unmeasured-state comparison was not established by the original
aggregate errors. Those scores are not carried forward as confirmed predictions.

The earlier generator variant has already been run and inspected. Subsequent
runs are sensitivity analyses and do not regain sealed status. The historical
plan did not fix the numerical cooling exponent; 0.85 was an implementation
choice. No independently timestamped freeze commit exists before October 31.

The existing PIONEER probe does not establish three labelled interlayer thermal
series or measured per-layer height. Its thermocouple plot uses layer peaks,
and its scans describe final geometry. There is no auditable calibration fit,
so the project no longer claims calibration or real-cell validation.

## Preserved records

`reports/archive/` contains previous experiment outputs and a ZIP snapshot of
the source and documents before this revision. The old stage labels and original
wording remain only in historical records. No earlier predictions or results
were silently rewritten to match the corrected analysis.
