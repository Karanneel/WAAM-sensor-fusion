# Earlier experiment records

These files predate the corrected 2026-11-01 protocol and are retained for
provenance. Do not use their headlines or pass statements as current findings.

- `source_before_revision.zip`: source and documentation as found before editing.
- `previous_experiments/`: model-error, dropout and variant outputs from the local working copy.
- `previous_sensor_analysis/`: earlier subset and covariance analysis.
- `previous_data_probe/`: earlier PIONEER figures.

The first committed version remains available in local Git history. Original
stage labels may appear inside these historical records. Current entry points
write to `reports/experiments`, `reports/sensor_selection` and `reports/data_probe`.
See `docs/decisions/revision-2026-11-01.md` for the corrections.
